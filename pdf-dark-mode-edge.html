PDF Dark Mode

PDF dark mode for Edge

Same extension, same license key, native Edge Add-ons install.

Setup

  1. Install from Edge Add-ons.
  2. Open any online PDF.
  3. Press Ctrl+Shift+1 or click the toolbar button.
  4. Tune Darkness and Contrast; save per-site rules (Pro) for hosts like arXiv.

Enable local files

Open edge://extensions, open PDF Dark Mode Details, turn on Allow access to file URLs, then refresh the PDF tab.
